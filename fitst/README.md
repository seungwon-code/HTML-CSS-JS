1. a tag 사용법 - 네비게이션

- href 속성 부여
  1. url : 다른 웹 사이트로 이동함
     - 주소값을 입력하면 되는데 http 또는 https + :// 다 적어줘야 작동
  2. #id : 해당 아이디와 동일한 아이디를 태그로 이동
     - 이동 시킬 태그에 id값 작성
     - a 태그 href 안에 # + id 와 동일한 값을 넣으면 연결
     - 연결된 태그 누를 때마다 주소창의 맨 끝 속값이 변경
  3. 파일명 : 예) index.html 해당 파일로 이동 전환
     - href 안에 파일명 적어준다
  4. 파일 다운로드 : 파일
